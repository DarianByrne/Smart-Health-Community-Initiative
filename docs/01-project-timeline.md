# Project Timeline

> **Purpose:** A high-level, chronological view of the whole project — the phases and the key milestones within them. Unlike the [Gantt chart](./02-gantt-chart.md) (which tracks scheduled task durations), the timeline is about _when the big moments happen_.
>
> **Update:** At the start of the project, then whenever a milestone is reached or a date shifts.

**Last updated:** _YYYY-MM-DD_ · **Maintained by:** _\<Your name\>_

## Timeline at a Glance

_Replace the example entries below with your own phases and events. Each `section` is a phase; each line is `Period : Event : Event`._

```mermaid
timeline
    title <Project Title> — Project Timeline
    section Phase 1 · Inception
        Week 1  : Project kickoff & supervisor meeting
                : Topic confirmed
        Week 2-3 : Literature review
                 : Define aims & objectives
    section Phase 2 · Design
        Week 4-5 : Requirements specification
        Week 6-7 : System / solution design
                 : Proposal submission
    section Phase 3 · Implementation
        Week 8-12  : Core build — iteration 1
        Week 13-16 : Core build — iteration 2
    section Phase 4 · Evaluation
        Week 17-18 : Testing & evaluation
        Week 19    : Results analysis
    section Phase 5 · Delivery
        Week 20-21 : Dissertation write-up
        Week 22    : Final submission
                   : Demonstration / viva
```
